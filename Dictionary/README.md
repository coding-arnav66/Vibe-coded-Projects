# Interactive Dictionary 📖🔍

A Python-based dictionary application that lets you look up word meanings, synonyms, and examples.  
It can work with a **static dictionary** (predefined words) or fetch definitions dynamically using APIs or web scraping.

---

## 🚀 Features

- Look up word meanings quickly
- Extendable with synonyms, antonyms, and examples
- Interactive mode: type a word and get its meaning
- Supports API-based lookups (e.g., Wordnik, Free Dictionary API)
- Optional web scraping fallback (e.g., Vocabulary.com)
