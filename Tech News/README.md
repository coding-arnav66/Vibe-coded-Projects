# Mini Tech Dashboard 🖥️📊

A Python desktop dashboard built with **Tkinter** that fetches and displays the latest content from **Dev.to**, **Hacker News**, and **GitHub**.  
It provides clickable links, charts, and a scrollable list of repositories — all inside a single GUI window.

---

## 🚀 Features

- **Dev.to Tab** → Shows latest articles with clickable links.
- **Hacker News Tab** → Displays trending stories with clickable links.
- **GitHub Tab** → Visualizes top repositories by stars using a bar chart.
- Scrollable list of GitHub repos with language and URL.
- **Refresh button** → Updates data live without restarting the app.
